확인일: 2026-11-03. 결과는 이 환경에서 실제 실행한 것으로, 전체 지역·기관 또는 다른 운영체제에서의 완전 재현을 뜻하지 않는다.

1. 원본 무결성: 다운로드한 첨부 96개의 크기·SHA256을 manifest와 비교해 일치 확인. 원본은 Git에 포함하지 않는다.
2. 날짜·추출·집계: 사용일 필터 및 정규화 검사. 추출 3327행, 주요 필드 기준 중복 후보를 묶은 3322행 중 기간 내 3321행. 해당 숫자를 확정된 고유 지출 건수라고 표현하지 않는다.
3. 자동 테스트: .venv/bin/python -m unittest -v, 9개 통과. 테스트 전 실패를 확인하고 날짜 서식·부서 집계·지도 검증을 구현했다.
4. 위치 근거: 지도 후보 4곳의 이름·주소·좌표를 실제 공개 위치 페이지에서 다시 읽어 대조. 정부 사업자 원장 대조나 영수증 단위 사업자 동일성 인증은 아니다.
