## 중간 구현물: 15점

| 항목 | 배점 | 대응 자료와 남은 일 |
| --- | --- | --- |
| 동작하는 MVP | 5 | 지역 목록·주소 전용 네이버 검색·이용기록 팝업. 실제 동작 장면을 영상 또는 수업 중 라이브로 보여야 한다. 캡처만으로 대신하지 않는다. 합성 예제는 UI 재현용이고 실제 12곳·160건 데모와 구분한다. |

제출물은 데모 링크를 포함한 구현 결과 슬라이드다. 평가표상 마감은 2026-11-06 23:59이고 늦으면 1점 감점이다. 기존 기획안 제출과 별개다. GitHub 업로드는 클래스룸 구현물 제출을 대신하지 않으며 이번 작업에서 클래스룸 제출물은 변경하지 않는다.

## 기말 소스 공개 가산점: 선택, 최대 +2

평가표의 조건:

- +2: 공개 GitHub 저장소에 README.md(문제·실행 방법), LICENSE, .gitignore, .env.example이 있고 README대로 실행 가능하며 비밀정보가 없다.
- +1: 공개했지만 README 실행 방법 또는 위 파일 일부가 빠졌다.
- 0: 공개하지 않았거나 과거 커밋을 포함해 저장소에 비밀정보가 있다.

이번 저장소는 사용자 요청대로 PRIVATE를 유지한다. 따라서 파일을 갖춰 업로드했더라도 현재 소스 공개 가산점 조건을 충족했다고 말하지 않는다. 공개 전환은 별도 사용자 승인과 전체 커밋 이력의 비밀정보 검토 후에만 한다.

기말에는 별도로 수업 밖 누구나 핵심 기능을 써 볼 수 있는 결과물 공개도 필수이며 공개 카드 마감은 평가표상 12월 11일 23:59다. 비공개 코드 저장소나 합성 UI 예제만으로 실제 식당 탐색 서비스의 공개 요건까지 충족했다고 주장하지 않는다.

## 업로드 경계와 재현성

- 포함: 자체 소스, 합성 자동 테스트, 명시적인 합성 예제, 자체 문서와 라이선스.
- 제외: 다운로드 원본, 실제 거래/식당 자료, 실제 기록 포함 HTML, 검토/승인 JSON, 원문 증거, 세션·로그인 정보.
- 새로 받은 코드는 README Quick Start로 합성 3곳·6건의 화면을 재현한다. 원래의 실제 12곳·160건은 로컬 연구용이며 복제로 재현되지 않는다.
- 키·비밀번호·토큰·연락처는 파일이나 커밋 메시지에 쓰지 않는다. 패턴 검사만으로 비밀정보와 개인정보가 완전히 없음을 보증하지 않는다.
