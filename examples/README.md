# 합성 UI 예제

이 폴더의 식당 3곳·기록 6건은 코드 실행을 확인하기 위해 만든 가짜 입력입니다. 실제 업소·주소·기관·공개 집행기록이 아닙니다. 로컬 연구 결과인 12곳·160건과 혼동하지 마세요.

모든 상호에 [합성] 표시가 있고 주소에도 실제 장소가 아님을 명시했습니다. 날짜는 연구기간 밖인 2000년입니다. example.com 링크는 예약된 예시 도메인이며 원문 자료가 아닙니다. 지도 검색을 눌러도 실제 식당을 찾는 예제가 아닙니다.

실제 자료는 원본·주소·목적문장·기관 근거·선정 조건·승인 해시를 별도로 검토해야 합니다. 합성 예제는 이 검토나 지역 식당 확보를 대체하지 않습니다.

실행 방법은 상위 README의 Quick Start를 따르세요. 외부 자료 수집이나 API 키 없이 목록 정렬·지역 필터·기록 팝업을 재현합니다. 자체 제작 합성 예제에는 프로젝트 MIT LICENSE를 적용합니다.
